## 빙고 — 부를 때마다 줄 수 세기
코드: [bingo.c](bingo.c), 입력: [data.txt](data.txt)

5×5 빙고판과 사회자가 부르는 25개 숫자가 주어진다. 몇 번째 숫자를 부른 뒤 빙고가 3줄 이상 되는지 구한다.

```c
/*
1. 아이디어
- 가로, 세로 대각선 확인

2. 시간복잡도
- O(N^3) < 125

3. 자료구조
- board[5][5] : int
- poses[25]: node
*/

typedef struct {
    int r;
    int c;
}pos;

pos p[N * N + 1];   // p[숫자] = 그 숫자가 있는 칸
int row[N + 1];     // row[r] = r행에서 지워진 칸 수
int col[N + 1];
int dLeft;          // ↘ 대각선에서 지워진 칸 수
int dRight;         // ↙ 대각선에서 지워진 칸 수
int nums[N * N + 1];
int cnt;            // 완성된 줄 수

void initData() {
    for(int i = 1; i <= N; i++) {
        for(int j = 1; j <= N; j++) {
            int n;
            scanf("%d", &n);
            p[n].r = i;
            p[n].c = j;
        }
    }

    for(int i = 1; i <= N * N; i++) {
        scanf("%d", &nums[i]);
    }
}

int bingo() {
    for(int i = 1; i <= N * N; i++) {
        check(nums[i]);
        if(cnt >= 3) return i;
    }
    return 0;
}

int check(int n) {
    int pr = p[n].r;
    int pc = p[n].c;

    if(++row[pr] == 5) cnt++;
    if(++col[pc] == 5) cnt++;
    if(pr + pc == 6) if(++dRight == 5) cnt++;
    if(pr - pc == 0) if(++dLeft == 5) cnt++;
}
```
```
입력
11 12 2 24 10
16 1 13 3 25
6 20 5 21 17
19 4 8 14 9
22 15 7 23 18
5 10 7 16 2
4 22 8 17 13
3 18 1 6 25
12 19 23 14 21
11 24 9 20 15

출력
15
```
- **판을 저장하지 않고 숫자 → 위치 표를 만든다.** `p[숫자]`에 행과 열을 저장하면 부른 숫자를 판에서 찾을 필요가 없다.
- **줄마다 지워진 칸 수를 센다.** 숫자를 부르면 그 칸의 행, 열, (해당하면) 대각선 카운트를 1씩 올린다. 5가 되는 순간 그 줄이 완성된 것이다.
  - `↘` 대각선은 `행 == 열`, `↙` 대각선은 `행 + 열 == 6`(1부터 셀 때)이다. Day13 N-Queen의 대각선 판별과 같은 원리다.
- `== 5`일 때만 세서 같은 줄을 두 번 세지 않는다.
- 판 전체를 매번 확인하면 25번 × 12줄 × 5칸이지만, 이 방식은 숫자 하나에 O(1)이다.
- ⚠️ `freopen("datat.txt", ...)`는 파일 이름 오타다. 파일이 없으면 열기에 실패하고 키보드 입력을 기다린다.
- ⚠️ `check`는 값을 반환하지 않으므로 `void`로 선언한다.
